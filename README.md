# Anand Bora — Portfolio

Full-Stack Developer at Flid AI. Live at https://anandbora.pages.dev

React 18, TypeScript, Vite and React Three Fiber. Hosted on Cloudflare Pages; deploy with `npx wrangler pages deploy dist --project-name anandbora`.

```bash
npm install
npm run dev     # local dev server
npm test        # content, accessibility and config checks
npm run build   # typecheck, sitemap, production build
```

Project images are real screenshots of each app running locally with sample data. A project without one shows no image.
